# Synthetic Examples

All examples in this directory are fictional and exist only to demonstrate the governance model. They must not be replaced with a real personal registry, private project inventory, unpublished research identity, or real machine path.

Included scenarios:

- cloud + local research workspace;
- active repository with GitHub source and local execution;
- cloud-only information hub;
- persistent brand with a supporting content system;
- multi-machine local lab using a reusable workspace standard;
- intentionally deferred placement-policy mismatch.

The examples are illustrative rather than a substitute for the normative rules in `SPEC.md`.
